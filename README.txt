# Supply Chain Vehicle Fill Rate Optimization

## Overview
A supply chain optimization project developed during my internship in the FMCG sector to improve Vehicle Fill Rate (VFR) through data-driven SKU-to-vehicle allocation.

## Problem Statement
Vehicle utilization was affected by differences between standard vehicle capacity assumptions and actual usable loading dimensions, SKU geometry, height constraints and SKU combinations.

## Approach
- Analysed SKU and vehicle dimensions
- Developed vehicle and SKU master datasets
- Performed exploratory data analysis
- Developed SKU-to-vehicle allocation logic using Python
- Used optimization constraints to improve vehicle utilization
- Considered SKU dimensions, vehicle dimensions and rotation constraints
- Developed supporting Excel-based tools

## Technologies
- Python
- Pandas
- NumPy
- Excel
- Excel Solver
- VBA
- Data Analysis
- Optimization

## Key Insights
- Identified gaps between standard and actual vehicle capacity
- Analysed the impact of SKU mix and SKU geometry on vehicle utilization
- Developed an optimization approach for improved vehicle loading

## Disclaimer
This repository contains only recreated/anonymized data and methodology for demonstration purposes. No confidential company data or proprietary information is included.
